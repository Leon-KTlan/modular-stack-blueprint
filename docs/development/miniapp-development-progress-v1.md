# “开耍”小程序开发进展

- **文档版本**：V1.0
- **文档状态**：Active（阶段快照）
- **最后更新**：2026-10-21
- **代码范围**：`apps/miniapp` 及其依赖的社区服务端能力
- **当前阶段**：M1 原生界面壳已完成；登录、请求层和真实业务联调待开发

## 1. 当前结论

“开耍（PARTNER）”已经具备可在微信开发者工具中运行的原生小程序界面壳。首页、圈子、发布、消息、我的和帖子详情均已落地，五项自定义底部导航可以切换，点赞、加入圈子、分类选择和发布校验提供本地演示交互。

当前页面数据均为演示数据，不能视为已完成端到端业务。服务端已经具备分类、帖子、点赞和一级评论接口，但小程序尚未实现微信登录、JWT 签发、统一请求层以及这些接口的真实联调。圈子用户端接口、“运动搭子”种子数据、通知和媒体上传也尚未完成。

## 2. 已完成内容

### 2.1 品牌与产品边界

- 中文主品牌确定为“开耍”，英文 `PARTNER` 作为辅助标识。
- 视觉方向确定为暖白背景、橙色主行动、深绿色辅助、校园生活图片和轻量手绘元素。
- 图标方向确定为橙色圆角方形、打开的门、星光和长投影。
- 一级导航确定为“首页 / 圈子 / 发布 / 消息 / 我的”。
- “运动搭子”已确认为第四个预设圈子方向，但数据库 seed 和真实接口尚未落地。
- V1 不包含实时私信、关注关系、推荐算法、活动报名和位置匹配。

### 2.2 原生小程序工程

- 新增 `apps/miniapp`，使用 TypeScript、WXML 和 WXSS。
- 实现自定义 tabBar，并突出中间“发布”入口。
- 实现首页、圈子、发布、消息、我的和帖子详情页面。
- 实现本地点赞、加入圈子、分类选择和空内容校验等演示交互。
- 对图片上传、搜索、关注、通知已读和私信等未接入能力给出明确占位或禁用提示。
- 提供 `project.config.example.json`；真实 AppID 只保存在 Git 忽略的本地配置中，AppSecret 不进入小程序代码和仓库。

### 2.3 页面完成度

| 页面 | 当前状态 | 真实数据状态 |
|---|---|---|
| 首页 | 静态界面与演示点赞已完成 | 帖子列表、详情和点赞接口待接入 |
| 圈子 | 我的圈子、热门圈子和加入反馈界面已完成 | 用户端圈子查询、加入、退出接口待实现 |
| 发布 | 圈子、分类、正文选择和本地校验已完成 | 登录、我的圈子、分类和发帖接口待联调 |
| 消息 | 互动、私信、系统三段视觉结构已完成 | V1 通知模型、接口、未读和已读状态未实现；私信非 V1 |
| 我的 | 演示身份、我的帖子和我的圈子入口已完成 | 微信身份、真实资料和退出登录待实现 |
| 帖子详情 | 正文、互动区和一级评论视觉已完成 | 详情、点赞、评论和作者删除接口待联调 |

### 2.4 可复用的服务端能力

- 社区用户、圈子、成员、分类、帖子、媒体、点赞和评论数据表已实现。
- `GET /api/miniapp/categories` 已实现。
- 小程序帖子列表、详情、纯文字发布、作者删除接口已实现。
- 帖子点赞、取消点赞、一级评论列表、发布评论和作者删除评论接口已实现。
- 小程序 JWT Guard 已存在，但微信登录与令牌签发流程尚未实现。
- 后台已经具备小程序用户、圈子、分类、帖子和评论管理能力。

## 4. 尚未完成

### 4.1 M1 剩余项

- 服务端微信 `code2Session` 登录与小程序 JWT 签发。
- 小程序环境配置、统一请求层、令牌保存与 `401` 恢复策略。
- 真实用户资料、加载态、空状态、失败态和重试。
- 隐私政策、用户协议和反馈入口。
- 后台 JWT 与小程序 JWT 的越权隔离验证。

### 4.2 后续业务闭环

- 通过幂等 seed 新增“运动搭子”，并同步 smoke 和数据文档。
- 小程序圈子列表、详情、加入、退出和“我的圈子”接口。
- 首页、详情、点赞、评论和纯文字发布的真实数据联调。
- 点赞、评论和系统通知的数据模型、接口、未读角标和已读状态。
- 对象存储、媒体上传、头像和圈子封面。
- 正式图标矢量资产、名称核验、隐私合规和真机验收。

## 5. 推荐开发顺序

1. **完成登录与请求层**：先打通 `wx.login`、服务端签发、令牌续用和错误处理。
2. **完成圈子闭环**：落地“运动搭子”seed 与小程序圈子接口，让发布页获得真实可选圈子。
3. **接入社区内容**：依次接入分类、帖子列表、详情、点赞、一级评论和纯文字发布。
4. **实现消息 V1**：在数据库和 API 文档确认后实现互动与系统通知，不提前开发私信。
5. **补齐上线门禁**：正式品牌资产、隐私协议、内容治理、合法域名和真机测试。
