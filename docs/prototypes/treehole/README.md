# 树洞 HTML 设计样板

状态：可交互的本地设计原型，尚未移植到微信小程序或连接后端。直接用浏览器打开 `index.html` 并排比较；`a.html`、`b.html`、`c.html` 可独立体验。无需安装依赖、启动服务或访问外部字体/CDN。

**最终选择：用户于 2026-10-24 选定 B「午夜电台」。** 后续 AI 必须按 [B 版原生复刻规范](../../development/treehole-frontend-b-spec-v1.md)实施。A/C 和比较页先前的推荐仅为历史评审资料；B 原型保持原样。当前等待用户开发指令，不开始修改正式小程序。

## 三个方向

| 版本 | 视觉方向 | 内容结构 |
|---|---|---|
| A 林间小门（历史备选） | 森林绿、奶油白、层叠门洞和叶子 | 独立入口 + 留白卡片，更容易融入当前小程序 |
| B 午夜电台（用户已选定） | 深蓝夜色、暖黄光线、电台刻度 | 独立入口 + 平铺文字分隔，更安静、适合长时间阅读 |
| C 心事邮局 | 奶油纸、朱红信箱、邮戳与信纸齿边 | 独立入口 + 来信卡片，校园感更强 |

入口周围用鼓励和接纳的短句，允许低落与抱怨，不要求用户保持乐观。三版共享相同业务流程，方便只比较视觉方向；插画是本地 SVG，内容区仍然只允许文字。

## 交互与“我的”设计

1. 入口页只介绍氛围、匿名和期限；点击门洞或按钮后进入帖子页。主 Tab 保留在入口页，帖子页使用返回导航。
2. 帖子按最新顺序展示，右下独立操作栏放「＋」和「我的」，为按钮预留高度，不遮挡帖子正文。支持详情、评论/回复弹层、点赞/取消点赞和举报。
3. 发布使用底部弹层，正文按 Unicode 码点统计，上限 1,000；评论 500。展示期可选 1/6/12/24 小时，默认 24 小时。
4. 样板统一演示“已提交，待审核”分支：提交后只出现在“我的”里，不插入公开列表。真实低风险直发仍按产品规范实现，本原型不模拟审核引擎。
5. “我的树洞”是私人内容管理入口，不设计头像、全局匿名昵称或公开主页。包含“我的帖子”“我的评论”和“树洞处罚与申诉”，支持取消投稿和确认删除。到期与删除记录不做历史归档。
6. 单版页面外侧提供“正常体验 / 空内容状态 / 受限与申诉”选择器；手机宽度下位于样板工具条。受限状态阻止帖子入口，仍可访问本人管理和申诉，隐藏既有内容，展示原因、受限能力、结束时间与申诉期限，不展示内部计分。
7. “首页”“消息”仅提示回到现有产品页面，不伪造本次范围外的功能。状态栏、胶囊和示例日期只用于设计预览。

表单以纯文字展示输入，刷新页面恢复初始样例；不请求后端、不向第三方发送文字、不存 localStorage。投稿配额、真实倒计时、每日限额、审核、举报去重和权限校验均需由后端实施，不应把本地原型当成安全控制。已演示的交互不代表功能已上线。

## 文件

- `index.html`：三版并排选择页。
- `a.html` / `b.html` / `c.html`：各方向独立入口。
- `styles.css`：手机画布、三版视觉与响应式样式。
- `app.js`：示例数据、页面导航和本地表单交互。

依据：[树洞 V1 产品与后端技术规范](../../architecture/treehole-design-v1.md)。本轮未改变业务契约、数据库或正式小程序文件。B 方向已选定；收到后续开发指令后，再制作 WXML/WXSS/TS 并验收真实胶囊、安全区与键盘行为。
