# “开耍”Expo App 两天黑客松计划 V1

## 1. 成功标准

Android 手机通过 Expo Go 扫码后，能够完成：

```text
进入演示 -> 浏览帖子 -> 查看详情 -> 点赞 -> 评论
         -> 发布纯文字帖子 -> 查看个人资料
```

小程序目录零改动；服务端现有小程序接口行为不变。

## 2. 第一天：独立客户端和主要视觉

1. 沉淀架构、开发约束和环境说明。
2. 创建 `apps/mobile`、Expo Router 和五项导航。
3. 建立主题、DTO、统一 API client、SecureStore 会话。
4. 完成登录、首页、帖子详情、个人资料主要视觉。
5. 在 Android Expo Go 完成首次真机启动。

当天停止条件：手机能扫码进入 App，并能用演示数据走通首页到详情。

## 3. 第二天：真实业务闭环

1. 增加受环境变量保护的演示登录。
2. 接通帖子列表、详情、点赞和一级评论。
3. 接通纯文字发布。
4. 为圈子、消息和未实现能力提供稳定降级页面。
5. 真机验证弱网、401、空数据、键盘和安全区。
6. 运行移动端、服务端、小程序类型检查和全量构建。

## 4. 功能优先级

| 优先级 | 能力 | 失败时处理 |
|---|---|---|
| P0 | Expo Go 启动、导航、登录、帖子列表和详情 | 阻断交付，立即修复 |
| P0 | 点赞、评论、纯文字发布 | 缩小页面装饰，保住闭环 |
| P1 | 个人资料真实数据 | 可回退到缓存并标注 |
| P1 | 圈子展示 | 使用明确标记的演示卡片 |
| P2 | 消息视觉 | 只交付建设中状态 |

## 5. 演示环境准备

- 服务端：`MOBILE_DEMO_AUTH_ENABLED=true`。
- 服务端：`MOBILE_DEMO_USER_ID=<已加入可用圈子的启用用户 ID>`。
- 服务端：安卓真机局域网联调时设置 `HOST=0.0.0.0`，演示结束后恢复默认值。
- 移动端：`EXPO_PUBLIC_API_BASE_URL=<Android 真机可访问地址>`。
- 提前准备至少一个启用分类、一个可用圈子、演示用户成员关系和三条帖子。
- 现场保留离线演示数据，但不得把离线互动描述为已写入后端。

## 6. 验证清单

```bash
pnpm --filter @cangqiong/mobile typecheck
pnpm --filter @cangqiong/server typecheck
pnpm --filter @cangqiong/miniapp typecheck
pnpm build
pnpm --filter @cangqiong/server smoke
```

真机检查：

- 冷启动、重新进入和 Token 恢复。
- 五项导航及 Android 返回键。
- 帖子刷新、详情、点赞、评论、发布。
- 服务端关闭、Token 失效和空列表。
- 小屏幕键盘遮挡、安全区和长文本换行。

## 7. 已知技术债

- 移动端暂时复用 `/api/miniapp/*` 业务路由，命名不代表长期公共 API。
- 演示身份仍对应 `miniapp_users`；正式产品需要独立身份决策。
- 圈子加入/退出和“我的圈子”接口尚未形成移动端闭环。
- 收藏、足迹、私信和消息没有服务端契约。
