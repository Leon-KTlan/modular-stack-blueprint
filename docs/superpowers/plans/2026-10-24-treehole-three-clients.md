# 树洞三端并行实现计划

用户已授权三端同时开发。契约版本 1.0.0，视觉固定 B「午夜电台」。

## 范围与共同约束

- 唯一结构来源：`docs/api/treehole-openapi-v1.json`；语义和产品依据：`docs/api/treehole-api-contract-v1.md`、`docs/architecture/treehole-design-v1.md`。
- 共享 DTO 使用 `@cangqiong/api-contracts/treehole`，禁止手改产物或私改冻结接口。发现缺口交由主协调者统一处理。
- 三端在当前已有基线的工作区按目录所有权并行；现有基线未提交，不能新建空缺基线的 worktree 或覆盖已有用户修改。禁止提交、推送和运行破坏性数据库操作。
- 无学生绑定、投票、精选、延期或身份查询。正文纯文本。业务 ID 始终十进制字符串，服务端内部 bigint。
- AI 使用 OpenAI 兼容接口，通过环境变量配置地址、模型、密钥；未配置或失败保持待审，不假装审核通过。正文/凭证不进入日志。
- 存储保留期限仍未确认：实现查询到期失效与待审关闭；不擅自设定物理清理期限、不清除未结证据。
- 小程序和后台各自可显式启用独立 Mock，默认不改普通社区请求地址、不把假令牌写入真实登录存储。

## 文件与责任

| 任务 | 所有权 | 共同接口 |
|---|---|---|
| 1 小程序 | `apps/miniapp`，包括现有 circles、个人中心入口、树洞页面/服务/装饰资源和测试 | 20 个小程序/本人操作，B 视觉 |
| 2 服务端 | `apps/server`、`database/migrations`、`.env.example` | 33 操作、11 表、worker 和 OpenAI 兼容 AI |
| 3 后台 | `apps/admin` | 13 个后台操作、4 类案件 |
| 4 协调集成 | `docs`、`AGENTS.md`、共享契约工具与必要根配置 | 文档状态、校验、跨端复核 |

接口共享而源码不重叠；三端任务各自内部的服务层、页面/路由与测试共同交付。已有未提交的 home/hot-ranking/mobile 等改动不属于本轮，不得回退。数据库 migration 与 Drizzle Schema 必须同步。
